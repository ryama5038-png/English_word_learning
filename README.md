## 1. 従来の書籍形式の英単語帳が抱える課題

何十年もの間、英語学習の主流であり続けている書籍（紙）形式の単語帳には、学習効率や継続性の観点から以下の構造的課題が存在します。

1. **「弱点のみの反復」が構造的に困難**
   - チェックボックスや付箋を貼っても、結局はページ全体を目で追ってしまい、すでに知っている単語を無駄に周回する非効率が発生する。
2. **アクティブリコール（想起訓練）の不完全さ**
   - 赤シートで隠す作業は物理的な手間がかかり、前後の単語の並び順（配置）で無意識に意味を覚えてしまう「位置記憶の罠」に陥りやすい。
3. **モチベーション管理の外部依存**
   - 単語学習は「最も成果が見えにくく、退屈な作業」であり、学習者の強固な意志力に依存しているため、途中で挫折しやすい。

## 2. 本プロダクトのアプローチ（課題の解決策）

本アプリケーションは、フルスタックのWeb技術（FastAPI + React）により、これらの課題をデータ駆動とUXデザインで解決します。

* **完全な個別最適化データベース（`user_words`中間テーブル）**
  - ユーザーごとの検索履歴、正答数、誤答数を記録。「直近で間違えた単語のみ」「付箋を貼った単語のみ」を瞬時に抽出し、100点になるまで繰り返す弱点特化型クイズを生成。ほかにも様々な用途や難易度に応じたテストが行えます。

## 3. 既存のデジタル単語帳・英語学習サービスとの決定的な差別化（Unique Value Proposition）

Anki、Quizlet、Duolingoなどの既存サービスと比較した、本アプリならではの**唯一無二の強み**は以下の3点です。

| 比較項目 | 一般的なデジタル単語帳 (Anki等) | 大手英語学習アプリ (Duolingo等) | **本プロダクト (Cyber Aquarium)** |
| :--- | :--- | :--- | :--- |
| **復習のトリガー** | 能動的にアプリを開き、カードをめくる必要がある | プッシュ通知による外発的動機づけ | **ホーム画面のペットによる「環境的・無意識の復習」** |
| **単語選定** | ユーザーの手動作成、または配布デッキに依存 | コース固定（画一的な文章・単語） | **辞書検索履歴・テスト誤答ログに基づく完全個別最適化** |
| **モチベーション設計** | 単調な暗記作業（継続が困難） | 一般的なストリークやバッジ | **時間経過減衰するサイバーペットの生命維持（愛着の喚起）** |

### ① 「眺めているだけで覚える」環境的アンビエント復習（忘却曲線の最適化）
一般的な単語帳は「テストを解く」という能動的な労力を要求しますが、本アプリではホーム画面に常駐するホログラムペットが、バックエンドで計算された最適な優先順位で単語をつぶやきます。
> **つぶやき優先度アルゴリズム**:  
> `直近のテストで間違えた単語` ➔ `現在学習中（しおり周辺）の単語` ➔ `すでに正解した単語`

アプリを開いてペットを愛でているだけで、最も復習すべき単語が無意識のうちに視覚へ刷り込まれます。

### ② 放置減衰型ゲーミフィケーション（生命維持の責任感）
単なる「ポイント付与」ではなく、**「最終アクセスからの経過時間に応じてペットのエネルギーが自動減衰する」**設計を採用。
- エネルギーが低下するとペットのセリフが衰弱したものに変化。
- 単語テストで獲得したクレジット（CR）を使って給餌（CHARGE）や最適化（OPTIMIZE）を行うことで、生命を維持。
- ユーザーに「自分が勉強しないとペットがお腹を空かせてしまう」というポジティブな愛着と責任感を生み出し、日々の継続率を底上げします。

### ③ サイバーパンク × グラスモーフィズムUI & PWA対応
学習意欲を掻き立てるネオングローと半透明のすりガラス（Glassmorphism）デザインを採用。PWA化により、スマートフォンではブラウザのアドレスバーを排した完全なネイティブアプリ体験を提供します。

## 4. 技術スタック

* **Backend**:
  - Python 3.11 / FastAPI (非同期API設計)
  - SQLAlchemy 2.0 (Async) + PostgreSQL
  - 認証: JWT (HttpOnly, SameSite Cookie による強固なXSS対策)
* **Frontend**:
  - React 18 / Vite
  - Tailwind CSS 
  - Web Speech API (`SpeechSynthesis`)
  - PWA (Progressive Web Apps / Service Worker)
